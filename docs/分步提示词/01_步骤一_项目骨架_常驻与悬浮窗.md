# 步骤一：项目骨架、后台常驻与悬浮窗

> **前置**：已读 00 总览；本机 .NET SDK 8 可用（`dotnet --info`）。
> **目标**：建立可运行的 WPF 骨架：双击运行后常驻后台（托盘可见），桌面出现三层亚克力方板悬浮窗，带悬停/消散动画、拖动与边界约束、位置持久化，并为后续步骤留好全部接口。

## 任务

### 1. 解决方案与工程骨架

1.1 仓库根创建 `Cship.sln` + `src\Cship\`（`dotnet new wpf -n Cship -o src\Cship`），并按 00 第 5.1 节建齐目录（`core\ models\ ui\...`）。

1.2 `Cship.csproj` 关键配置：

```xml
<PropertyGroup>
  <OutputType>WinExe</OutputType>
  <TargetFramework>net8.0-windows</TargetFramework>
  <UseWPF>true</UseWPF>
  <UseWindowsForms>true</UseWindowsForms>   <!-- 仅 NotifyIcon / Screen 用 -->
  <AssemblyName>Cship</AssemblyName>
  <Nullable>enable</Nullable>
  <ApplicationManifest>app.manifest</ApplicationManifest>
</PropertyGroup>
<ItemGroup>
  <!-- 外置资源复制到输出目录，保证开发态/发布态路径逻辑一致 -->
  <Content Include="dependencies\resources\**\*" CopyToOutputDirectory="PreserveNewest" TargetPath="dependencies\resources\%(RecursiveDir)%(Filename)%(Extension)" />
</ItemGroup>
```

1.3 `app.manifest`：`dpiAwareness = PerMonitorV2`（含 `dpiAware` 兼容回退）；`longPathAware`；**不要** `requestedExecutionLevel=RequireAdministrator`（禁止 UAC）。

1.4 `core\Paths.cs`：`AppDir()`（`AppContext.BaseDirectory`）、`DepsDir()`、`ConfigDir()`、`ResourcesDir()`、`AssetsDir()`、`IconCacheDir()`、`LogsDir()`；启动时确保 `config\ iconcache\ assets\ logs\` 存在。

1.5 `SettingsStore` / `StateStore`（System.Text.Json）：读写 00 第 8 节键表、缺键补默认、原子写（`*.tmp` + `File.Replace`）、防抖 300ms 落盘；变更事件 `SettingsChanged(key, value)` 供全局广播。

1.6 `core\I18n.cs`：`Tr(key)` 静态类，启动加载 `dependencies\resources\i18n\zh-CN.json / en-US.json`（缺失键回退英文再回退 key 本身）；`Reload()` 支持语言热切换。

### 2. 程序入口与常驻

2.1 `App.xaml.cs`：`OnStartup` 中先做单实例 → 装配日志 → 创建托盘 → 显示悬浮窗；`DispatcherUnhandledException` / `AppDomain.UnhandledException` / `TaskScheduler.UnobservedTaskException` 三处全局异常钩子写日志。

2.2 单实例 `SingleInstance`（`Mutex` 名 `"Cship_SingleInstance_Mutex"`）：第二实例通过命名 `EventWaitHandle` 发 `activate` 后退出；首实例收到后让悬浮窗播放一次"呼吸"动画（三板间距 6→10→6，各 250ms）。

2.3 命令行参数 `--autostart`：静默启动标记（07 步用），本步先解析存入全局。

### 3. 托盘常驻【原文 L2、L73】

3.1 `TrayController`：`System.Windows.Forms.NotifyIcon`，图标运行时绘制（GDI+ 画 256px 三层错开圆角半透明方板 → 转 Icon），tooltip `Cship`。

3.2 左键单击托盘：收纳板开→收起；未开→悬浮窗呼吸动画（收纳板 02 步接入）。

3.3 右键菜单本步用 WinForms 原生菜单临时实现四项：**偏好设置**（disabled 占位，05 接通）/ **复位** / **重启** / **关闭**。所有动作封装为 `TrayController` 的公共方法/事件（06 步将替换为自绘玻璃菜单窗，直接复用动作）。

3.4 `Logger`（core）：按天写 `logs\cship_yyyyMMdd.log`，7 天自动清理（本步建基础版即可）。

### 4. 悬浮窗 FloatingDock【原文 L3、L4、L8】

4.1 窗口基类 `GlassWindow`（`ui\components\`）：`WindowStyle=None`、`AllowsTransparency=True`、`Background=Transparent`、`ShowInTaskbar=False`、`Topmost`（由派生类按 4.8 模式设定，不在此写死）、圆角裁剪（`Border CornerRadius` + Clip）；封装"屏幕坐标/DPI 换算"辅助（`Visual.PointToScreen` + `VisualTreeHelper.GetDpi`，PerMonitorV2 下手动换算物理像素）。

4.2 三层方板组件 `SquarePlate`：三个 `Border`（默认 56×56、圆角 12、半透明亚克力预设观感：亮 `#CCF9F9F9` / 暗 `#CC1F1F1F` + 1px 顶边高光 + 程序生成的 64×64 轻噪点 `ImageBrush`；封装材质占位参数，06 步 MaterialEngine 接管）。层序：上板最前，三板各向右下错开 6px。

4.3 悬停动画【L3】：`MouseEnter/MouseLeave` 触发 Storyboard：三板偏移 6→10px，250ms `CubicEase(EaseInOut)`，同步；移出倒放。

4.4 单击消散【L4】：按下后位移 <4px 且 <300ms 判定为点击 → Storyboard：三板偏移 6→16px（120ms）且 Opacity→0，播完 `Hide()` 窗口。本步单击后仅做"消散 → 延时 600ms → 原地反向复现"占位演示；02 步改为：消散后打开收纳板，收纳板关闭后悬浮窗以消散倒放复现。

4.5 拖动【L8】：鼠标左键按下+移动跟随（手动实现：`PointToScreen` 换算，勿用 `DragMove`——无法做阈值判定）；松手校验：窗口必须完整落在所选屏 `Screen.WorkingArea` 内，越界夹回最近合法位置；`display.screen=auto` 时允许跨屏拖动（拖到哪块屏算哪块屏）。`advanced.dockLocked=true` 禁用拖动（本步先读键生效）。

4.6 首次运行（`state.json` 无 `dock.pos`）：位置=所选屏工作区顶部水平居中、上留 16px【L8】。

4.7 位置持久化：拖动结束 500ms 防抖写 `dock.pos`；启动时校验（分辨率变化后夹回合法区）。

4.9 启动/退出出入场（2026-08-30 批次十，用户反馈）：程序启动 `Show()` 后播 `PlayIntro()`=三板自消散态聚合复现（复用 `SquarePlate.PlayRevive`，250ms），替代冷启动瞬间直弹；托盘"关闭/退出/重启"经 `App.ExitWithFade` 播 `PlayExit()`=消散编排（三板分离+淡出 250ms）后回调，动画结束才 `Shutdown`/拉起新进程。收纳板开着时退出：板先滑出（`CloseBoard(revive:false)`，悬浮窗本已隐藏、不复现），动画完再收尾。动画期间悬浮窗状态机处于非 Idle 态，悬停/点击守卫自然拦截误触发。

### 4.8 悬浮窗优先级（z 序）模式【原文 L60】

FloatingDock 启动时与 `advanced.dockPriority` 变更时调 `ApplyPriority(mode)`（`DockZOrder`）：

- `high`（默认）：`Topmost=True`（保持现状）。
- `medium`：`Topmost=True`，但留全屏前台窗口检测钩子（`SystemBridge.IsForegroundFullScreen(screen)`，07 步实现）：检测到所选屏真全屏前台 → `Hide()` 悬浮窗（或 `Topmost=False` 退入普通层，二选一记于 STEP_LOG）；全屏退出 → 恢复 `Topmost=True` + `Show()`。本步先留空接口与空实现，默认行为等同 `high`，实际检测 07 步接通。
- `low`：`Topmost=False`，并对 hwnd 子类化拦截 `WM_WINDOWPOSCHANGING` 强制 `HWND_BOTTOM`（或周期 `SetWindowPos(HWND_BOTTOM)`，方案记 STEP_LOG），使其始终位于普通窗口之下；不影响单击消散等其他逻辑。

模式切换即时生效（监听 `SettingsChanged` 中 `advanced.dockPriority` 键）；`SettingsStore` 缺键回退 `high`。BoardWindow 等其他 GlassWindow 派生类各自设定自己的 Topmost 策略，不受此键影响。

### 5. Esc 路由骨架

`ShortcutRouter` 静态类：`EscPressed()` → 依注册顺序询问（分类页 > 收纳板 > 设置窗）；各窗口用 `PreviewKeyDown` 或 `InputBindings` 接入。本步仅留空实现与 API。

## 技术指引与坑

- 透明无边框窗口：`AllowsTransparency=True` 必须与 `WindowStyle=None` 同现，否则 XAML 报错。
- 顶置窗口 `Topmost` 在焦点被抢后可能失效：监听系统前景事件太重，改为收纳板打开期间临时取消悬浮窗 Topmost 即可（本步可不做，记录到 STEP_LOG）。4.8 的 `medium` 模式所需"真全屏前台检测"同此坑——07 步用轮询（复用指示灯线程）+ 必要时 `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 兜底，不在此监听。
- GDI+ 画托盘图标后务必 `icon.Dispose()` 旧实例再换新，否则句柄泄漏。
- Mutex 放在 `try/finally` + `GC.KeepAlive`，防止早回收导致误判多实例。
