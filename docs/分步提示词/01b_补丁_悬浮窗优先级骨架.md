## 任务

### 1. SettingsStore 键登记

1.1 默认值表新增 `advanced.dockPriority = "high"`（对齐 00 §8）。旧 `settings.json` 无此键时启动自动补 `high`——补丁前后行为完全一致（原实现即恒置顶）。

### 2. GlassWindow 基类调整

2.1 移除写死的 `Topmost=True`：初始 `Topmost=False`，改由派生类在构造/`SourceInitialized` 时自行声明置顶策略（如 `protected virtual void ApplyTopmostStrategy() {}` 或等价机制，记 STEP_LOG）。
2.2 其余基类行为（透明/圆角裁剪/DPI 换算辅助）一律不动；FloatingDock 现有全部行为不得回归。

### 3. FloatingDock 三档优先级（01 第 4.8 节落地）

3.1 `DockZOrder` 枚举（`low/medium/high`）+ `ApplyPriority(DockZOrder)`：

| 档 | 实现 |
|---|---|
| `high` | `Topmost=True`（现状行为，默认） |
| `low` | `Topmost=False` + 子类化 hwnd 拦截 `WM_WINDOWPOSCHANGING`：flags 不含 `SWP_NOZORDER` 时强制 `hwndInsertAfter=HWND_BOTTOM`，使其始终位于普通窗口之下 |
| `medium` | 行为暂等同 `high`；新增空钩子 `OnForegroundFullScreenChanged(bool)`（仅 API+日志），真检测 07 步接通；本补丁仅在 `SystemBridge` 加返回 `false` 的占位签名 `IsForegroundFullScreen(Screen)` |

3.2 启动时读键调 `ApplyPriority`；监听 `SettingsChanged` 中 `advanced.dockPriority` 即时切换（当前无 UI 触发源，监听正确性留 05 复验，记 STEP_LOG）。
3.3 模式切换必须清理旧模式钩子（`HwndSource.RemoveHook`），避免 low 残留强制置底；先 `Topmost=False` 再挂钩子（顺序反了会被 DP 覆盖）。

## 技术指引与坑

- `WM_WINDOWPOSCHANGING` 用 `HwndSource.FromHwnd(Handle).AddHook`；改 `WINDOWPOS` 须 `Marshal.PtrToStructure` 读出 → 改 `hwndInsertAfter` → `Marshal.StructureToPtr` 写回；**钩子内禁止再调 `SetWindowPos`**（重入）。
- 常量：`HWND_BOTTOM = (IntPtr)1`；`SWP_NOZORDER = 0x4`。
- 消散动画的 `Hide/Show` 与置底不冲突：若观察到 low 模式复现时短暂浮到普通层之上属正常，下一次 `WM_WINDOWPOSCHANGING` 会夹回，记录即可。
- 回归范围：悬停/消散/拖动夹边/位置持久化/单实例呼吸/托盘四项——全部重验，不许只测新功能。
