# 步骤二：收纳板、桌面文件陈列与交互

> **前置**：步骤一完成（骨架/托盘/悬浮窗/存储层可用）；已读 00 总览。
> **目标**：实现收纳板窗口：三层结构、锚边定位、可调长宽、枚举并陈列系统桌面全部文件（图标+名称）、自绘右键菜单、垃圾桶拖拽删除、全部文件操作，与悬浮窗单击联动。

## 任务

### 1. BoardWindow（`ui\BoardWindow.xaml`）【原文 L9-13】

1.1 继承 `GlassWindow`（圆角 12、透明、无边框；出现期间 `Activate()`）。三层结构（z 自上而下）：
- **L1 图标网格层**：ScrollViewer + 自定义面板（WrapPanel 变体，支持行/列间距与 iconOrder 自定义布局；>300 项走分批加载，见决策 3）；
- **L2 材质背景层**：`MaterialBackground` 占位（06 步接管）；
- **L3 自定义背景图层**：读 `personal.boardBg`（副本路径 + crop 四边形），显示于 L2 之上 L1 之下、圆角遮罩；无则 `Collapsed`。

1.2 定位（依 `advanced.popupDirection`，默认 `auto`）：

| 方向 | 锚边（贴所选屏**屏幕边缘**，非任务栏/工作区） | 可调边 | 位置记忆 | 空白拖动 |
|---|---|---|---|---|
| up（自下向上） | 下边缘贴屏幕下边缘（可覆盖任务栏） | 上/左/右 + 上两角 | `board.pos.up` | 仅横移 |
| down | 上边缘贴屏幕上边缘 | 下/左/右 + 下两角 | `board.pos.down` | 仅横移 |
| left | 左边缘贴屏幕左边缘 | 右/上/下 + 右两角 | `board.pos.left` | 仅竖移 |
| right | 右边缘贴屏幕右边缘 | 左/上/下 + 左两角 | `board.pos.right` | 仅竖移 |
| center | 无锚边（四边不贴屏） | 四边 + 四角 | `board.pos.center` | 自由移动 |

- **方向来源**：`auto`=按悬浮窗位置推断——悬浮窗贴哪条屏幕边（中心距边 ≤110 物理像素）就从哪条边滑出，距四边都远则 center（自中心放大"果冻"弹出）；固定值直接指定。
- 位置与悬浮窗解耦：用户调整过（缩放/拖动均落盘 `board.pos.<direction>`）下次同方向恢复；未调整过则默认屏幕居中（up/down 横向居中，left/right/center 纵向亦居中）。
- 锚定边不可调尺寸；锚边一侧有过渡阴影（越贴屏幕边缘越重），center 无阴影；锚边一侧两角为直角、整体留约 6px 在屏幕外。
- 越界夹回按屏幕完整边界（锚定轴不参与夹回，以免撤销出屏余量）。
- 拖动收窄为**仅标题栏区域（34px 带）可拖动**（原文 L13"不可拖动"经用户反馈放开后收窄；方向约束同表）。

1.3 大小调节：可调边 8px 拖拽热区，相邻可调边交汇处另有 14px 角部热区（斜向双向调尺寸）；min 480×320，max=所选屏完整边界；尺寸按方向持久化 `board.size.<direction>`；中、下层圆角一致【L13】。**缩放期间行列冻结**（图标被窗口边缘裁切属预期），四边显示窄"阴影渐变条"软化边界（锚定边不加）；结束后图标动画过渡到新位置。

1.4 右上角常驻控件（z 最高）【L10】：关闭=红色小圆点 `#FF5F57` 无图案，位于**最右上角**；**设置齿轮在关闭红点左边**（水平排列、26px 等高对齐）；hover 尺寸变化带过渡动画（缓动补间，非瞬变）；齿轮+关闭共用一块柔和投影，垃圾桶独立投影。齿轮点击→发事件（05 接设置窗）；红点→收起收纳板。

1.5 右下角常驻控件：垃圾桶图标（自绘），拖拽删除目标（任务 5）。

1.6 内容区右侧滚动条自绘现代化样式：细轨（约 6-8px）、圆角滑块、半透明、跟随亮暗主题，不用系统默认宽滑块；顶部让位右上角按钮列。

1.7 顶部标题栏带：宽约 34px，材质区别于主体（同色系略深/略亮一档），下缘渐变渐隐、交界不生硬；带位于网格层之下，不遮挡图标与指示灯；下边界以 1px 低不透明度淡线勾勒；**该带同时是窗口拖动移动的热区**。

1.8 滚轮平滑滚动：滚轮不再逐格跳跃，目标偏移经渲染帧插值缓动逼近（约 120ms 收敛）。

1.9 拖拽收纳：**桌面已有文件/文件夹拖入板身=无效**（不复制、不提示）；**非桌面文件拖入=不复制源文件**，只在收纳板新增一个仅收纳板存在的"快捷方式"（`state.virtualItems` 持久化，源文件可随时移删，图标与打开均指向源路径）。**实时腾位**：悬停板身某区域 >100ms 后该区域后的图标先行腾出空位，拖到别的区域→空位迁移，取消/失败→空位恢复，落座即插入该空位、不再二次移动。**无绿膜/系统"复制+"角标**（DragOver 报 Move 效果）。悬停格号判定带 **14px 迟滞带**（格边界微抖不来回切换空位），Drop 落点仍用精确格号。**取消只认"光标真出板矩形"的 DragLeave**：板内 DragLeave 忽略（仅记日志），DragEnter 兼作 DragOver 处理——实测 OLE 拖动经过分层窗口时 Leave 高频误报、Over 大量缺席，信 Leave 会引发"腾位→误补位→再腾位"循环。

1.10 图标过渡动画：图标增删、拖动换位、腾位、补位、缩放结束重排等视觉跳跃一律平滑过渡（渲染帧插值 ≈120ms 收敛）。**出入场过渡**：新出现的图标淡入+自 0.85 微放大（150ms）；移除/删除/watcher 检测的文件消失先缩小淡出（200ms）再移除模型、后方缓动补位——出现与消失都不是瞬间跳变。

1.11 线性序列紧凑布局：布局=线性序列（row-major），任何移除/删除/外部刷新/拖动后按当前视觉顺序紧凑重排（被移除项留下的空位由后方图标顺移补齐，不留空位）；新增项缀尾；拖动到某格=移动插入（后方顺移）而非交换。

### 2. 桌面枚举与数据模型

2.1 `DesktopScanner`（`core\`）：
- 枚举范围：用户桌面（`Environment.GetFolderPath(SpecialFolder.DesktopDirectory)`）+ 公共桌面（注册表 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders` 的 `Common Desktop`）；同名用户项优先；排除隐藏/系统属性（`File.GetAttributes`）与 `desktop.ini`。
- 类型判定：目录→`folders`；`.exe/.bat/.cmd`→`apps`；`.lnk`→动态 COM 解析目标后判定（目标 exe/bat→`apps`、文件夹→`folders`、其余→`files`；失败归 `files`）：

```csharp
dynamic wsh = Activator.CreateInstance(Type.GetTypeFromProgID("WScript.Shell")!)!;
dynamic sc = wsh.CreateShortcut(lnkPath);
string target = sc.TargetPath;   // 用完 Marshal.ReleaseComObject
```

- 图标提取通道次序：① `.url` 解析 `[InternetShortcut]` 的 IconFile/IconIndex → `SHDefExtractIcon`（256px）；② `IShellItemImageFactory`（256px ICONONLY），但结果与"通用空白页图标"基准一致时视为失败（实测本机对 .url/.txt 会 S_OK 返回通用图标并误缓存）；③ `SHGetFileInfo`（32px，走 shell 图标处理器）兜底。存 `config\iconcache\<sha1(path+mtime)>.png`（缓存键含版本盐，通道修正后升盐全量重提取）。
- **文件夹图标**统一用内置 `dependencies\resources\icons\folder.png`（源自 素材\文件夹.webp 转制，裁边+8% 边距归一化），不进按路径缓存；资源缺失时回退系统提取。【原文 L10"文件夹图标用系统默认"由用户反馈取代】
- `FileSystemWatcher` 监视两个桌面目录，防抖 500ms（`DispatcherTimer`）后增量刷新；目录消失/异常不崩；刷新保持 iconOrder/滚动位置。本步基础版，07 步加固。

2.2 `BoardModel` / `BoardItem`（`models\`）：`ObservableCollection<BoardItem>` + 排序（名称/大小/类型/修改时间 × 升/降，默认名称升序）；过滤 `advanced.showApps/showFiles/showFolders`；属性 `Name/Path/Type/IconPath/SizeBytes/Mtime/IsRunning/Row/Col`，另含 `IsVirtual`（外部拖入的虚拟快捷方式）与 `DisplayName`（.lnk/.url 不显扩展名，显示层专用）。`iconOrder` 语义为**当前布局快照**（只含可见项，线性序列紧凑式，见 1.11）。

### 3. 图标项 `IconItem`（`components\`）【原文 L6、L36-41、L53-58】

3.1 网格参数（iconSize/rowSpacing/colSpacing/名称开关/不透明度）全部实时响应设置键（监听 `SettingsChanged`）。

3.2 hover：整体上跳 6px（`TranslateTransform` + 200ms `QuadraticEase(EaseInOut)`），离开倒放；**上行必播完**——离开时若上行尚未播完，待其结束后再回程。

3.2b 名称显示：快捷方式（.lnk/.url）**不显示扩展名**（仅显示层；iconOrder、重命名、移除名单仍用真实文件名）。

3.3 悬停文件名（`display.hoverLabels`）：图标上方黑底白字气泡，黑底边缘虚化（`RadialGradientBrush` 作 opacity mask），淡入 150ms。

3.4 遮罩（`advanced.iconMask`）：白色圆角底板（圆角=25% 边长）先绘，原图标 `Uniform` 缩放居中其上，任何原图标不得越界。

3.5 `iconStyle=hoverReveal`：所有图标初始 opacity=0（名称正常显示），指针位置半径 96px 内图标平滑淡入至设定不透明度（250ms），离开淡出【L36】。

3.6 指示灯（`advanced.runningIndicator`）：6px 绿点，图标上方 4px（不得被标题栏遮挡）；检测：`Process.GetProcesses()` 比对主模块文件名（.exe 按名、.lnk 按目标名、文件夹按进程路径前缀，忽略大小写）；`DispatcherTimer` 2s 轮询（07 步移入后台线程）。

3.7 弹跳打开（`advanced.bounceOpen`）：跳起 0.5×图标高 → 回弹 0.25/0.12/0.06 递减（落地瞬间 5% 横向挤压），完成回调里才执行 `FileOps.Open`【L57】。弹跳在**窗口根层幽灵**上播放：网格内原图标临时压暗、位图复制到根层宿主播放同款关键帧，不受 ScrollViewer 裁剪——首行图标可覆盖标题栏带。

3.8 打开方式：双击（`advanced.dblOpenItems` / `dblOpenFolders` 分别控制）；单击=选中（**无视觉描边**，仅内部选中状态）。开关关闭时双击仅选中。双击容错：首击已升级为拖动（微位移>阈值）时，双击作废拖态直接打开；**同一文件打开冷却 1.5s**（防连点重复打开/弹跳叠加）。

### 4. 自绘右键菜单 `GlassPopup`（`components\`，不用系统样式）【原文 L14-15、L75】

4.1 通用样式：`Popup`（`AllowsTransparency`）内 Border：圆角 12、占位材质背景、主题色文字/hover 蒙层、出现动画（锚点 `ScaleTransform` 0.95→1 + 淡入 120ms）、关闭动画（淡出 + 锚点微缩 0.96，130ms easeIn，关闭期间禁命中）、投影 `DropShadowEffect`（四周 16px 留白完整渲染，圆角无脏边，放置偏移不重复补偿）。子菜单向右展开，右侧放不下时整体翻转到母菜单左侧（不与母菜单叠加）；悬浮在母项/子菜单上保持开启；点击全部弹出层之外任意处关闭；Esc/选择后关闭；收纳板关闭连带关闭；支持图标/勾选态/禁用态。

4.2 空白处右键：**排序方式＞**（名称/大小/类型/修改时间 + 升序/降序，当前项打勾）｜**刷新**｜**新建＞**（文件夹 / 文本文档 / 快捷方式——~~快捷方式弹输入框填目标路径后创建 .lnk~~ **[2026-10-05 批次六]** 改为系统选择窗口：`快捷方式`=系统"打开"对话框（筛选=所有文件）+`快捷方式（文件夹）`=系统"选择文件夹"对话框，不再手填路径）。新建落在桌面→刷新可见。

4.3 图标右键：**打开**｜**移除**（不在收纳板显示，非删除；记入 `state.removedItems`，刷新不找回）｜**打开文件所在位置**（`explorer.exe /select,"path"`）｜**固定到开始屏幕**（`ShellExecuteEx` verb=`pintohome`，不可用时隐藏）｜**复制**（`Clipboard.SetFileDropList`）｜**重命名**（图标处内联 `TextBox`，回车确认、非法名拦截）｜**[2026-10-05 批次六] 删除**（取消显示+删源文件=回收站，复用垃圾桶链路）｜**属性**（`ShellExecuteEx` verb=`properties`）。

### 5. 垃圾桶删除【原文 L10】

从图标按下拖动（位移 ≥4px 进入拖动）→ 半透明拖影跟随（**拖动期间隐藏被拖文件的文件名**；**拖影渲染在独立顶层弹出层，拖出到收纳板外仍全程可见**）→ 悬停垃圾桶时高亮+微放大+危险色 → 松开**进回收站**：

```csharp
Microsoft.VisualBasic.FileIO.FileSystem.DeleteFile(path,
    UIOption.OnlyErrorDialogs, RecycleOption.SendToRecycleBin);
// 目录用 DeleteDirectory(..., DeleteDirectoryOption...)
```

图标缩小淡出 200ms；拖到别处松开=取消。拖动期间**原位置不显示原图标**（起拖 150ms 淡出、松手 150ms 淡入恢复）；拖到无效位置松开→拖影 200ms 过渡回原位。**拖出收纳板外松开=移除**（仅取消显示、不删源文件；虚拟项则彻底从 virtualItems 删除；拖影 200ms 淡出即消失动画，播完才移除模型+后方缓动补位）。
【补充决策】`advanced.lockIconDrag=true` = 禁一切图标拖动（含换位与拖删）。
【语义】移除=取消文件在收纳板的显示；删除=取消显示+删源文件；拖入垃圾桶=取消显示+删源文件（回收站）。右键"移除"先播缩小淡出再移除模型。

**[2026-10-05 批次六] 拖到文件夹图标上=移入该文件夹**：以目标图标**原始中心**为圆心、图标宽度 1/3 为半径的圆内→该图标四周浮出粗描边（与图标留 6px 间距、线宽 3px、圆角随图标；黑主题白/白主题黑，出现与消失 150ms 渐变）；圈外不触发（仍走上面的换位/移出/拖删语义）。圈内松开=把源文件/文件夹移入目标文件夹（同名 "(2)" 递增**不覆盖**，拒绝自嵌套）→原图标缩小淡出、从模型摘除、后方图标紧凑补位。

## 技术指引与坑

- `Clipboard.SetFileDropList` 需要 STA（WPF UI 线程天然 STA，直接用）。
- P/Invoke 全部集中在 `SystemBridge`；图标提取按 2.1 通道次序（旧 `SHGetFileInfo`+`SHIL_JUMBO` 逐级回退方案已废弃——本机 `SHGetImageList` 恒 `E_NOINTERFACE`，见决策 1）。
- HICON→像素统一走 `GetIconInfo`+`GetDIBits`（旧 `Icon.FromHandle().ToBitmap()` 方案已弃用）。
- `FileSystemWatcher` 内部线程事件必须 `Dispatcher.Invoke` 回 UI 线程。
- 内联重命名 TextBox 要 `Focusable` 且吃掉鼠标事件冒泡（`e.Handled=true`），避免触发图标拖动。
- WrapPanel 无虚拟化：>300 图标走分批 `Dispatcher` 加载（低优先级后台逐批添加），取舍见 STEP_LOG 决策 3。
