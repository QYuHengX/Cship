# 步骤三：动画系统与预设框架

> **前置**：步骤一、二完成；已读 00 总览（时长/缓动/默认参数标准）。
> **目标**：统一动画基础设施：全局动画帧率（响应刷新率设置）、缓动映射规范、收纳板开合动画预设注册表（≥5 套，含"吐出/吸入"）、悬浮窗动画复查、图标微动效参数集中化，供 02/04/05/06 调用。

## 任务

### 1. AnimationClock（`ui\animations\`）

1.1 WPF 动画帧率控制统一用 `Timeline.DesiredFrameRate`（进程级，设置在所有 Storyboard 的时间轴上）：`general.fps` → 60/90/120/165 即时生效（`Timeline.SetDesiredFrameRate(timeline, fps)`）。
   > **记录局限**：实际渲染受显示器 vsync 与 WPF 渲染线程限制，165 帧档表现为"尽可能快"；此取舍必须写进 STEP_LOG。

1.2 `Anim.Run(...)` 辅助：输入（目标元素、属性、from/to、时长 ms、缓动枚举、完成回调）→ 内部构造 `DoubleAnimation` + `DesiredFrameRate` + `Completed` 一次性订阅，供各处一行调用；同时提供多属性并行/串行组合辅助。

### 2. 缓动映射规范（`AnimTuning` 静态类，常量唯一来源）

| 项目缓动名 | WPF 实现 |
|---|---|
| linear | 无 EasingFunction |
| easeInOutQuad | `QuadraticEase { EasingMode = EaseInOut }` |
| easeOutCubic / easeInCubic | `CubicEase { EaseOut / EaseIn }` |
| easeOutBack（过冲 ≤1.08） | `BackEase { EasingMode=EaseOut, Amplitude=1.5 }`（峰值恰 1.08；旧 ≈0.35 峰值仅 1.003，决策 76） |
| bounce 衰减序列 | `DoubleAnimationUsingKeyFrames` 手工关键帧（见 3.4） |

时长常量：`Micro=150ms`、`HoverJump=200ms`、`Enter=350ms`、`Exit=250ms`、`ThemeFade=300ms`、`MenuPop=120ms`、`DockDissolve=250ms`（悬浮窗消散/复现；旧的 `DockVanish=120ms` 已作废，见 STEP_LOG 决策 77）。
**后续步骤只准引用 AnimTuning，禁止散落魔法数字**（本步结束时 grep 校验 02 步代码）。

**过渡动画覆盖要求（原文 L79，全局铁律）**：凡视觉上的"跳跃式变化"必须补过渡动画，至少覆盖——图标/内容的增删与换位、面板与菜单的显隐、按钮/hover 反馈、滚动、主题换装、状态切换（开/关、选中/未选）、数值跳变（滑轨/滑块）。动画参数一律取自本文件与 `AnimTuning`；确实无法动画的硬约束（如物理边界夹回）须在 STEP_LOG 写明。

### 3. 收纳板动画预设注册表 BoardAnimPresets【原文 L5、L63】

接口：每预设 = `{ Id, I18nName, Open(board, dockPos, anchorEdge, Action onDone), Close(board, dockPos, Action onDone) }`。至少 5 套（全部用代码构造 Storyboard，操作 `ScaleTransform/TranslateTransform/Opacity`）：

| Id | 名称 | 打开 | 关闭 |
|---|---|---|---|
| `expand` | 展开（默认） | 锚边方向：从锚边屏幕外平移滑入 + 淡入 350ms easeOutCubic（00 §7 现行口径，决策 75）；center：自窗口中心 scale 0.1→1 + 淡入 | 倒放滑出 250ms easeInCubic |
| `spitOut` | 吐出/吸入 | 先在悬浮窗处压缩至 0.4（150ms easeIn），再向锚边方向 easeOutBack 弹开 350ms | 被"吸回"悬浮窗：反向收缩 250ms + 末端缩至 0.2 淡出 |
| `slideEdge` | 滑出 | 依锚边从屏幕边滑入 300ms easeOutCubic | 滑回 |
| `popBounce` | 弹跳 | scale 0→1.06→1 两段 400ms | 缩至 0.9 淡出 |
| `fadeSoft` | 淡化 | opacity 0→1 + 上移 8px 300ms | 倒放 |

注册表可扩展（05 步设置页枚举生成选项与预览）。**动画期间 Board 加全屏透明遮罩捕获输入**，防连点状态错乱；预设切换在关闭状态下生效；动画目标属性动画前先 `FillBehavior=Stop` + 手动复位，避免属性残留。

### 4. 图标微动效规范集中化

- hover 上跳：6px / 200ms easeInOutQuad，离开放。
- 弹跳打开关键帧（`AnimTuning.BounceKeys`）：高度 `[1.0, 0.25, 0.12, 0.06] × 0.5 × iconSize`，分段时长 `[220,200,180,160]ms`，落地接触 5% 横向挤压（ScaleX 1.05 / ScaleY 0.95，60ms）【原文 L57】。
- 垃圾桶删除消失：缩小 0.6 + 淡出 200ms。
- 菜单/气泡出现：120ms scale 0.95→1 + 淡入。

将 02 步散落数值全部替换为引用 `AnimTuning`。

### 5. 悬浮窗动画复查

对照 01 规格：hover 6→10px / 250ms；消散=中层停留、上/下板对角外扩并缩小、三板同步淡出，分离与淡出同 250ms（决策 13）；复现=倒放；呼吸提示动画。全部改用 `Anim.Run` + `AnimTuning`。

### 6. 主题切换过渡工具（供 06 步）

`ThemeFade.Transition(window, Action applyNewTheme)`：`RenderTargetBitmap` 截当前窗口 → 覆盖一个等尺寸 `Image`（顶端 z）→ 执行 `applyNewTheme()` → Image 淡出 300ms 后移除。颜色级插值不需要，快照交叉淡化即可满足"切换有过渡"【原文 L28】。

## 技术指引与坑

- 代码构造动画时 `Storyboard.Completed` 事件会保留目标引用，务必匿名订阅后 `-=` 或用 `RemoveStoryboard`，防内存泄漏。
- 同时动画同一 Transform 的两个属性（X/Y）要两个独立 `DoubleAnimation`，不能共用。
- `DesiredFramerate` 拼写（不是 FrameRate）注意大小写；它是附加属性，Timeline 子节点设置无效，须设在具体 Animation 或 Storyboard 上。
- 窗口位置动画用 `Left/Top` 依赖属性（WPF 单位，非物理像素），配合 DPI 换算。
